# Правила репозиторію

## Go-сервер

- Go module: `github.com/h0rn3t/rdl-mcp`, Go 1.27+, точка входу `cmd/rdl-mcp`, реалізація без публічного Go API у `internal/`.
- Golden fixtures для контрактних тестів зберігаються в `tests/testdata/rdl/`; Go-тести перевіряють JSON-результати структурно, а XML семантично.
- Використовуйте стандартну бібліотеку для XML, файлів і логування. Дозволені прямі залежності: офіційний `github.com/modelcontextprotocol/go-sdk` та `github.com/dlclark/regexp2/v2@v2.8.0`; інші прямі залежності потребують окремого погодження.
- Зберігайте імена tools, аргументи, default-и й результати. Записуйте прийняті відмінності та ризики в `MIGRATION.md`.
- Виконуйте OpenSpec завдання послідовними перевіреними зрізами. Позначайте завдання виконаним лише після перевірки.
- Для Go-змін запускайте `go build ./...`, `go vet ./...` і `go test -race ./...`; результати й невиконані перевірки записуйте в `MIGRATION.md`.
- Публікація Go artifacts і запис у MCP Registry потребують окремого рішення.
