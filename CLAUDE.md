# Інструкції для Claude Code

## Проєкт

RDL MCP — MCP-сервер для читання, перевірки та редагування звітів SSRS у форматі RDL.

## Основні правила

- Використовуйте Go 1.27 або новіший. Точка входу — `cmd/rdl-mcp`; внутрішня реалізація — у `internal/`.
- Виконуйте завдання `openspec/changes/migrate-rdl-mcp-to-go/tasks.md` перевіреними зрізами. Позначайте завдання виконаним лише після його перевірки.
- Зберігайте 15 MCP tools, їхні аргументи, default-и та форму JSON результатів. Контрактні fixtures розміщені в `tests/testdata/rdl/`.
- Для XML, файлів і логування використовуйте стандартну бібліотеку. Дозволені прямі залежності: `github.com/modelcontextprotocol/go-sdk` та `github.com/dlclark/regexp2/v2@v2.8.0`; інші потребують окремого погодження.
- Порівнюйте JSON структурно, XML семантично та перевіряйте збереження неторкнутого вмісту. Фіксуйте прийняті відмінності й невиконані перевірки в `MIGRATION.md`.
- Не публікуйте Go artifacts і не змінюйте MCP Registry без окремого рішення.

## Команди перевірки

```sh
go build ./...
go vet ./...
go test -race ./...
go mod tidy -diff
```

## Структура

- `cmd/rdl-mcp` — запуск stdio-сервера.
- `internal/mcpserver` — каталог MCP tools і диспетчеризація викликів.
- `internal/rdl` — читання, перевірка та редагування RDL.
- `tests/testdata/rdl` — зразки RDL і очікувані контрактні результати.

Сервер обмінюється MCP-повідомленнями через stdin/stdout. Діагностика має йти в stderr або файл через `RDL_MCP_LOG_LEVEL` та `RDL_MCP_LOG_FILE`.
